    How it works

    Prompts in, models out

    There is no tool palette to learn first. Every command of the engine, from a boolean to a render, is a function that the AI calls and checks on its own.

    You write

    Ask in plain words, in the ChatGPT chat. Attach technical drawings, a sketch, a photo or an address when you have them.

    The AI drives the engine

    It reads the request, calls the Gapsman functions one by one and checks each result. The model is drawn in the chat, and the reasoning runs underneath, step by step.

    You review and decide

    Correct in words, or take the mouse and edit in the same viewport. Every change is a new revision with its own code, so nothing is lost.

    Machine oriented

    The AI builds: it chooses the commands, measures, checks and writes what it is doing, one line at a time, under the model.

    Human interface

    The same model, in the same viewport, is fully editable by hand. The next prompt starts from the model exactly as you left it.

    Features

    What the machine draws for you

    Each function is written as a prompt. These are examples of what you can ask.

    From technical drawings

    The AI reads plans and sections, traces walls, openings and rooms level by level, and builds the model. A critic then compares it with the drawings.

    Build this house from the plan and the section.

    Camera match from a sketch

    From a sketch or a photo it finds the lines, the vanishing points and the camera, then draws the architecture in the same view.

    Rebuild this sketch in 3D, in the same view.

    Real neighbourhoods

    It finds the place, takes the buildings from OpenStreetMap, checks them on the satellite photo and reads the facades along the street.

    Add the real context around the site.

    Parametric, and free

    Walls, doors, windows, slabs, roofs, stairs: everything stays parametric. It also models freely, with curves, polygons, subdivision and a little sculpting.

    Make the roof steeper and the windows wider.

    Real furniture

    Furniture comes from a library of real products, with brand, model and measures, such as Muuto, Vitra, Cassina, HAY, Fritz Hansen and IKEA.

    Furnish the living room with a Muuto sofa.

    Gardens: RPC and ivy

    Real photographs of trees and people on cards that face the camera, with seasons, and a vegetation creator that grows ivy on the walls.

    Add trees and people, then grow ivy on the wall.

    It builds its own tools

    When a command is missing, the AI composes it from the commands it has, tests it on an empty scene and adds it to your tools.

    Make me a command for a spiral staircase.

    A critic before the build

    From drawings, the AI writes a checklist and a critique first. Building starts only after you approve it.

    Check the model against the drawings.

    Render to final image

    Path-traced render, ID render, layer adjustments, then the final image in ChatGPT, with the same camera and geometry.

    Render it from the terrace and make it photographic.

    FAQ

    Questions

    What is Gapsman?

    A 3D engine for architecture that runs as a plugin inside ChatGPT. You describe what you want in words, and the AI uses the engine to model, check and render it.

    Do I need to know 3D software?

    No. You work by writing prompts. If you want, you can also edit the model by hand in the same viewport.

    What can I attach to a prompt?

    Plans and sections, sketches, photos, and an address for the real context. The AI reads them and says what it understood before building.

    Is the model really parametric?

    Yes. Walls, doors, windows, slabs, roofs, stairs, furniture and ivy keep their parameters, so a correction in words changes the model instead of redrawing it.

    How is the final image made?

    Gapsman renders the model with a path tracer, makes an ID render with one colour and one code per material, adjusts the layers, and writes the prompt for the final image in ChatGPT, with the same camera and geometry.

    Who owns what I make?

    The models, drawings and renders you create with Gapsman are yours.

    Can I use the model to build?

    Gapsman checks geometry, not structure or building codes. A licensed professional is always needed.

    Which ChatGPT plan do I need?

    During early access Gapsman runs as a custom app, which requires a ChatGPT plan that allows custom apps. Write to us and we will tell you what fits your account.
